# PlaywrightLearning_AG

This repository contains Playwright learning examples and exercises used for PlaywrightLearning2026.

## Contents
- `chapter_01_Basics/` — example scripts for chapter 1 (basic Playwright usage).

## Prerequisites
- Node.js (recommended v18+)
- npm or Yarn

## Setup
1. Install dependencies:

```bash
npm install
```

2. (Optional) Install Playwright browsers:

```bash
npx playwright install
```

## Run examples

Run a single script with Node (examples are plain JS files):

```bash
node chapter_01_Basics/03_verify_setup.js
```

If you convert to Playwright test runner, use:

```bash
npx playwright test
```
